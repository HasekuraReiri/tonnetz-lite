# 输入语法

Tonnetz Lite 的所有输入框共用一套解析器：顶部快速输入、右侧“输入与检索”、底部“编辑和弦进行”都可以使用本文写法。

## 1. 和弦符号

### 1.1 基本结构

```text
根音 + 性质后缀 + 可选斜杠低音
```

例子：

```text
C
Cm
Cmaj7
C7
Cm7b5
Cdim7
Caug
Csus4
C/E
Am7/G
```

- 根音：`A`–`G`，可带 `#`、`b`、`♯`、`♭`，最多两个变音记号。
- 大小写：根音大小写均可；后缀区分大小写，但常用别名会兼容。
- 斜杠低音：只写音名，如 `/E`、`/Bb`，不写八度。
- 空格会被忽略，`C maj7` 与 `Cmaj7` 等价。

### 1.2 常用性质

| 后缀 | 和弦 | 音程（相对根音） |
|---|---|---|
| 空 / `maj` / `M` | 大三和弦 | 0, 4, 7 |
| `m` / `min` / `-` | 小三和弦 | 0, 3, 7 |
| `dim` / `o` / `°` | 减三和弦 | 0, 3, 6 |
| `aug` / `+` | 增三和弦 | 0, 4, 8 |
| `sus2` | 挂二 | 0, 2, 7 |
| `sus4` / `sus` | 挂四 | 0, 5, 7 |
| `5` / `power` | 强五度 | 0, 7 |
| `maj7` / `M7` / `Δ7` | 大七 | 0, 4, 7, 11 |
| `7` | 属七 | 0, 4, 7, 10 |
| `m7` / `min7` / `-7` | 小七 | 0, 3, 7, 10 |
| `m7b5` / `ø7` | 半减七 | 0, 3, 6, 10 |
| `dim7` / `°7` | 减七 | 0, 3, 6, 9 |
| `mM7` | 小大七 | 0, 3, 7, 11 |
| `aug7` / `7#5` | 增七 | 0, 4, 8, 10 |
| `7sus4` | 属七挂四 | 0, 5, 7, 10 |
| `6` | 大六 | 0, 4, 7, 9 |
| `m6` | 小六 | 0, 3, 7, 9 |
| `6/9` / `69` | 六九 | 0, 2, 4, 7, 9 |
| `add9` | 加九 | 0, 2, 4, 7 |
| `maj9` / `M9` | 大九 | 0, 2, 4, 7, 11 |
| `9` | 属九 | 0, 2, 4, 7, 10 |
| `m9` | 小九 | 0, 2, 3, 7, 10 |
| `7b9` | 属七降九 | 0, 1, 4, 7, 10 |
| `7#9` | 属七升九 | 0, 3, 4, 7, 10 |
| `7#11` | 属七升十一 | 0, 4, 6, 7, 10 |
| `7b13` | 属七降十三 | 0, 4, 7, 8, 10 |
| `maj7#11` | 大七升十一 | 0, 4, 6, 7, 11 |
| `11` | 属十一 | 0, 2, 4, 5, 7, 10 |
| `m11` | 小十一 | 0, 2, 3, 5, 7, 10 |
| `13` | 属十三 | 0, 2, 4, 7, 9, 10 |
| `maj13` | 大十三 | 0, 2, 4, 7, 9, 11 |

变化属和弦的常用写法：

```text
C7b9     C7#9     C7#11     C7b13
C7b5     C7#5     Cmaj7#11
```

也支持中文性质别名，例如 `C大三`、`Cm小三`、`C属七`、`C大七`。

### 1.3 转位与斜杠低音

```text
C/E          C 大三，低音 E（第一转位）
C/G          C 大三，第二转位
Am7/G        Am7，低音 G
F#dim7/C     F#dim7，低音 C
```

低音只影响低音标记与试听/四声部排列，不改变和弦的音级集合。注意 `6/9` 是性质后缀，不会被当作“斜杠低音”。

## 2. 音名列表

### 2.1 多个音名

用空格或逗号分隔：

```text
C E G
C,E,G
C E G B♭
F# A C# E
```

- 结果是一个音集，不要求符合三度叠置。
- 重复音会自动去重。
- 程序会尝试识别和弦；识别不出时按音集显示。

### 2.2 带八度

```text
C4 E4 G4
C3 G3 C4 E4
```

带八度时：

- 八度只用于确定低音与试听排列；
- 音级集合本身仍按 0–11 去重；
- 最低的带八度音会成为低音。

### 2.3 单个音

```text
C
C4
Bb3
F#5
```

单个音名可以在网格中定位一个音；单字母 `C` 同时也是一个和弦符号，因此单独输入 `C` 会按大三和弦处理。要明确表示单音，建议写八度，如 `C4`。

## 3. 音集（0–11）

### 3.1 方括号 / 花括号

```text
[0,2,4,5,9]
{0,1,4,6}
[0 2 4 7]
```

- 数字必须是 **0–11 的整数**；
- 逗号、空格均可分隔；
- 自动去重并升序排列；
- 支持 1–12 个音；
- 不要求写成音名。

### 3.2 不带括号

两个以上数字也可直接写：

```text
0 2 4 5 9
0,1,4,6
```

为避免歧义，教程与案例统一使用方括号。

### 3.3 0–11 对照

| 数字 | 音名 |
|---|---|
| 0 | C |
| 1 | C♯ / D♭ |
| 2 | D |
| 3 | D♯ / E♭ |
| 4 | E |
| 5 | F |
| 6 | F♯ / G♭ |
| 7 | G |
| 8 | G♯ / A♭ |
| 9 | A |
| 10 | A♯ / B♭ |
| 11 | B |

0 始终是 C，不随调性变化。顶栏的“0–11”按钮只改变显示方式，不改变实际音高。

## 4. 和弦进行

### 4.1 分隔

在“编辑列表”中，以下写法等价：

```text
C
Am
F
G
```

```text
C | Am | F | G
```

```text
C; Am; F; G
```

也支持混合换行与竖线。每个分隔出的片段必须能独立解析。

### 4.2 注释

`#` 之后的内容会被忽略：

```text
# 流行 1645
G | Em | C | D

# 爵士 ii–V–I
Dm7 | G7 | Cmaj7
```

注意：`#` 只有出现在行首或空白之后才开始注释，因此 `F#dim7`、`C#m7` 中的升号不会被误删。写行尾注释时，请在 `#` 前留一个空格。

### 4.3 空行与错误

- 空行会被忽略；
- 无法识别的片段会被跳过，并提示忽略数量；
- 如果全部无法识别，则不会载入，并提示检查格式。

### 4.4 进行中的音集

```text
[0,2,4,5,9] | [0,2,3,5,7,9,10] | [0,1,4,6]
```

音集环节同样会编号、着色并参与播放。

---

## 5. 调性与拼写

- 调性主音与调式在右侧面板选择，不在输入文本里写。
- 音名拼写会参考当前调性：降号调优先显示 `B♭`，升号调优先显示 `F♯`。
- 输入中显式写的根音拼写会尽量保留，例如 `F#dim7` 不会强制改成 `Gbdim7`。
- 切换调性会重新计算功能与罗马数字，但**不会自动移调**已输入的和弦。

## 6. URL 参数（可选）

页面支持通过查询参数打开一个预设视图，便于分享示例或嵌入教学页面：

```text
?tonic=7&mode=major&seq=G%20%7C%20Em%20%7C%20C%20%7C%20D
```

| 参数 | 值 | 作用 |
|---|---|---|
| `tonic` | 0–11 | 主音音级，0=C |
| `mode` | 调式 id | 如 `major`、`minor`、`dorian`、`lydian` |
| `naming` | `integer` | 切换为 0–11 显示 |
| `circle` | `fifths` / `chromatic` | 圆圈模式 |
| `chord` | 和弦文本 | 打开时显示该和弦 |
| `seq` | 进行文本 | 打开时载入进行，需 URL 编码 |
| `satb` | `1` | 尝试开启四声部网格 |

`seq` 中的空格、`|`、`#` 等字符需要 URL 编码。最简单的做法是：在页面中搭好示例，再用浏览器地址栏/分享工具生成链接。
