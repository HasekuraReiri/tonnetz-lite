# 常见问题

## 启动与页面

### 为什么不能直接双击 `index.html`？

页面使用原生 ES Module（`<script type="module">`）。浏览器在 `file://` 协议下会阻止模块跨文件加载，因此必须通过 HTTP 访问。请使用 `launch.cmd`（Windows）或 `python3 serve.py`（macOS/Linux）。

### 页面空白 / 一直显示“正在启动”

1. 确认地址栏以 `http://127.0.0.1:` 开头，而不是 `file:///`。
2. 打开开发者工具 Console，查看是否有 `Failed to load module script` 或 404。
3. 按 `Ctrl+F5` 强制刷新。
4. 确认 `assets/js/`、`assets/css/` 与 `index.html` 在同一目录结构中。

### Windows 双击没有反应

在 PowerShell 中打开项目目录，运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\launcher.ps1
```

观察报错。也可查看 `.runtime\launcher.log` 与 `.runtime\url.txt`。

### 端口被占用

Windows 启动器会在 `8850–8870` 中寻找空闲端口。若全部占用：

```powershell
# 查看占用
Get-NetTCPConnection -LocalPort 8850 -ErrorAction SilentlyContinue
```

也可以改用 `serve.py` 指定端口：

```bash
python3 serve.py --port 9000
```

### 为什么 `launch.cmd` 直接打开了已有页面？

启动器会先检查 `127.0.0.1:8850` 上是否已有 Tonnetz Lite。如果有（例如另一个副本正在运行），它会复用该实例。需要运行当前副本时，先停止旧实例或用 `serve.py --port` 指定新端口。

### macOS 提示 `start.sh: Permission denied`

```bash
chmod +x start.sh
./start.sh
```

或直接：

```bash
python3 serve.py
```

### 没有安装 Python，能用吗？

Windows 用户不需要 Python，`launch.cmd` 使用系统自带的 PowerShell。macOS/Linux 用户可以用任意静态服务器；若完全没有 Python/Node，建议使用 GitHub Pages 在线版。

## 声音

### 点击和弦没有声音

按顺序检查：

1. 先点击页面任意位置（浏览器自动播放策略要求一次用户手势）。
2. 右上角扬声器按钮是否处于开启状态。
3. 系统音量、浏览器标签页是否静音。
4. 换一个浏览器（推荐 Edge / Chrome）。
5. 打开 Console 是否出现 `AudioContext` 相关错误。

### 为什么普通进行和四声部音色不同？

普通和弦/进行使用钢琴合成音色；严格四部和声使用弦乐音色，按 S/A/T/B 的实际音高播放。这是刻意区分“和弦试听”和“四声部试听”。

### 能导出音频吗？

当前版本只导出 MIDI，不直接渲染 WAV/MP3。可以把 MIDI 导入 DAW 或制谱软件后使用音源导出音频。

## 输入与识别

### 为什么 `C` 被当成和弦，而不是单音？

单字母 `C` 同时是合法的大三和弦符号。要明确表示单音，请写八度，如 `C4`。

### 为什么某些和弦名无法识别？

输入使用固定语法，不支持任意自然语言。请检查：

- 根音是否为 `A`–`G`；
- 升降号是否写成 `#` / `b` 或 `♯` / `♭`；
- 后缀是否在 [输入语法](输入语法.md) 的表中；
- 斜杠低音是否只写音名（如 `/E`，不写 `/E4`）。

### 进行里的 `F#dim7` 为什么以前会被截断？

旧版把 `#` 后所有内容都当注释，导致 `F#dim7` 变成 `F`。当前版本仅在 `#` 位于行首或空白之后时才开始注释，因此 `F#dim7`、`C#m7` 可以正常使用。写行尾注释时请在 `#` 前留空格。

### 0–11 会随调性变化吗？

不会。0 始终是 C。顶栏“0–11”只改变显示方式；调性变化影响功能解释和圆圈朝向，不改变绝对音级编号。

### 切换调性会自动移调我的和弦吗？

不会。它只重新解释功能、罗马数字与拼写。要移调，请直接编辑和弦符号或重新载入进行。

## 和弦进行

### 支持哪些分隔符？

换行、`|`、`;` 都可以。`#` 在行首或空白后表示注释。

### 为什么只载入了一部分？

无法识别的片段会被跳过，并提示忽略数量。逐行检查拼写，尤其是七和弦后缀、斜杠低音和音集括号。

### 刷新后进行消失了

当前版本不保存工程，只在内存中维护进行。请先导出 MIDI，或使用“复制四声部”保存文本。后续如加入工程保存，会明确说明存储位置。

## 四部和声

### 绿色、琥珀色、红色分别是什么意思？

- **绿色**：硬性规则全部通过，无复核项。
- **琥珀色**：硬性规则通过，但有需要人工复核的声部进行。
- **红色**：存在硬性规则问题，严格无解；会给出最佳近似与修改建议。

### 为什么显示“最佳近似”？

进行无法在严格规则下完成四声部写作。程序返回违规最少的结果，用于定位问题；它不等同于严格答案，也不允许导出严格 SATB MIDI。

### 为什么我的九和弦被省略了音？

四个声部最多同时容纳四个不同音。含 5 个及以上音的和弦/音集需要省略、重复或重新排列；9 音以上通常无法完整放入 SATB。请把它当作边界提示，而不是自动编配结果。

### 为什么同一个进行改调后就变红/变绿？

调性影响导音、功能、调内音与拼写，进而影响候选与规则判断。请确认当前主音与调式是否符合分析目标。

### 可以把它当自动四部合唱编配器吗？

不建议。它是辅助检查与教学工具，不替代人工写作。正式作品请逐声部复核。

## MIDI

### 导出的 MIDI 是什么格式？

SMF format 1，4/4，480 TPQ，每和弦 4 拍。流行模式 1 个钢琴轨；严格 SATB 模式 4 个声部轨，Choir Aahs 音色。

### 为什么严格 MIDI 按钮是灰色的？

当前严格 SATB 无解。请先在“四部和声”面板修复问题，或改用一般（流行）导出。

### 导入 DAW 后没有声音？

检查：

- 是否导入了多轨；
- 轨道是否被静音；
- 当前音源是否支持 Program 52（Choir Aahs）；不支持时会回退为默认音色；
- 文件是否被识别为标准 MIDI。

### 可以导出 MusicXML 吗？

当前版本不提供。可以先导出 MIDI，再导入 MuseScore 等制谱软件。

## 隐私、数据与许可

### 会上传我的和弦或使用数据吗？

不会。页面没有外部请求、统计或账号系统。所有计算在浏览器本地完成。

### 数据存在哪里？

只有圆圈模式写入 `localStorage` 的 `tonnetz-lite:circleMode`。进行、调性、选择都不持久化。

### 可以用于商业项目或课堂吗？

代码以 MIT License 发布，允许使用、修改、分发与商业使用，但需保留版权与许可声明。音乐理论内容与第三方书名/链接归各自权利人；使用时请遵守所在机构与平台的要求。

### 可以修改后闭源发布吗？

MIT 允许，但必须保留原版权与许可声明。若你希望贡献回项目，欢迎提交 Pull Request。

### 如何引用本项目？

建议注明项目名、版本（当前整理版为 `v0.1.0`）、仓库地址与访问日期。若用于学术写作，请同时引用你实际使用的和声/音集理论来源，而不是只引用本工具。

## 其他

### 支持手机/平板吗？

界面为桌面工作台设计，小屏尚未专门优化。可以打开，但工具栏、侧栏与画布交互可能拥挤。

### 支持 Safari / Firefox 吗？

使用现代 Web 标准（ES Module、Canvas、Web Audio、ResizeObserver），现代版本理论上可用；主要在 Edge/Chrome 上验证。若遇到兼容问题，请附浏览器版本提交 Issue。

### 如何反馈问题？

请提供：

- 操作系统与浏览器版本；
- 复现步骤；
- 相关和弦进行文本；
- Console 报错与截图；
- 是否使用本地版或 GitHub Pages。

提交前请先搜索已有 Issue，避免重复。
