# 安装指南

Tonnetz Lite 是纯静态网页，**不需要安装框架、数据库或编译器**。安装的本质是：把完整的项目文件夹解压到本机，然后用一个本地 HTTP 服务打开 `index.html`。

> 直接把 `index.html` 拖进浏览器会因 ES Module 的同源限制而无法运行。请使用本文中的启动方式。

## 1. 环境要求

| 项目 | 要求 |
|---|---|
| 浏览器 | 最新版 Microsoft Edge、Google Chrome（推荐）；Firefox / Safari 现代版本也可尝试，但未重点验证 |
| 屏幕 | 桌面宽屏，建议 1440×900 或以上 |
| 网络 | 首次下载需要网络；运行与播放完全离线 |
| Windows | Windows 10 / 11，系统自带 PowerShell 5.1 |
| macOS / Linux | Python 3.8+（仅用于启动静态服务器） |
| 运行时 | 无需 Node.js、npm 或第三方 Python 包；Windows 无需额外运行时，macOS/Linux 仅需系统 Python 3；无需管理员权限 |

Windows 一键启动不依赖 Python；macOS / Linux 使用随附的 `serve.py`，只使用 Python 标准库。

## 2. Windows 安装

### 2.1 解压

1. 从 GitHub Release 下载 `Tonnetz-Lite-v0.1.0.zip`。
2. 右键 → **全部解压缩**，得到完整的 `Tonnetz-Lite` 文件夹。
3. 不要只把 `index.html` 拖出来；`assets/`、`launch.cmd` 等必须保持在同一目录结构中。

### 2.2 启动

双击：

```text
launch.cmd
```

启动器会：

1. 检查 `127.0.0.1:8850` 上是否已有 Tonnetz Lite；
2. 若没有，则在 `8850–8870` 中寻找空闲端口，隐藏启动 `lite-server.ps1`；
3. 用默认浏览器打开 `http://127.0.0.1:<端口>/`。

如果浏览器没有自动打开，查看：

```text
.runtime\url.txt
```

其中保存了本次启动的实际地址。

### 2.3 停止

双击：

```text
stop.cmd
```

停止脚本只识别**当前文件夹**的 `lite-server.ps1`，不会影响同机上的其他 Tonnetz 副本或别的本地服务器。关闭浏览器标签页不会自动停止服务，建议使用 `stop.cmd`。

### 2.4 创建快捷方式（可选）

双击 `create-shortcut.cmd`，会创建：

- 项目内的 `Tonnetz Lite.lnk`
- 桌面的 `Tonnetz Lite.lnk`

生成的 `.lnk` 已加入 `.gitignore`，不会被提交到仓库。

### 2.5 Windows 常见提示

| 现象 | 处理 |
|---|---|
| SmartScreen 提示“Windows 已保护你的电脑” | 确认文件来自本仓库后，点“更多信息”→“仍要运行”。所有脚本均为可读的 `.cmd` / `.ps1` 文本。 |
| 双击后一闪而过 | 在 PowerShell 中运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\launcher.ps1`，查看具体报错。 |
| 提示端口都被占用 | 关闭占用 `8850–8870` 的程序，或使用下文的跨平台启动方式指定其他端口。 |
| 页面空白 | 确认通过 `http://127.0.0.1:...` 打开，而不是 `file:///.../index.html`；再按 `Ctrl+F5` 强制刷新。 |
| 没有声音 | 先点击页面任意位置；检查右上角扬声器按钮是否开启，以及系统输出设备与浏览器标签页是否静音。 |

> 不建议以管理员身份运行。服务器只监听回环地址，通常不会触发防火墙提示。

## 3. macOS / Linux 安装

### 3.1 使用启动脚本

```bash
cd Tonnetz-Lite
chmod +x start.sh
./start.sh
```

脚本会依次寻找 `python3` 或 `python`（要求 3.8+），启动 `serve.py` 并打开浏览器。按 `Ctrl+C` 停止。

若压缩包解压后 `start.sh` 没有执行权限，`chmod +x start.sh` 即可；也可以直接运行：

```bash
python3 serve.py
```

### 3.2 使用任意静态服务器

项目没有构建步骤，任何能正确返回 `.js` MIME 类型的静态服务器都可以：

```bash
# Python 标准库
python3 -m http.server 8850 --bind 127.0.0.1

# 或 Node.js（需要已安装 Node）
npx serve . -l 8850
```

然后打开 `http://127.0.0.1:8850/`。

### 3.3 指定端口

```bash
python3 serve.py --port 9000
```

`serve.py` 会从指定端口开始，最多向后尝试 21 个端口。使用 `--no-browser` 可以只启动服务、不自动打开浏览器。

## 4. GitHub Pages 在线版

仓库已包含 `.github/workflows/pages.yml`，可把应用直接发布为静态站点：

1. 将项目推送到 GitHub 仓库的 `main` 分支。
2. 打开仓库 **Settings → Pages**。
3. 在 **Build and deployment → Source** 中选择 **GitHub Actions**。
4. 推送一次提交，或在 **Actions → Deploy static site to GitHub Pages → Run workflow** 手动运行。
5. 部署完成后访问 Actions 输出的 `page_url`。

因为应用没有后端，Pages 版与本地版功能一致。注意：Pages 是公开站点，不要把私人笔记或未授权素材放进仓库。

## 5. 验证安装

### 5.1 检查服务器

Windows PowerShell：

```powershell
Invoke-WebRequest -UseBasicParsing http://127.0.0.1:8850/api/ping | Select-Object -ExpandProperty Content
```

macOS / Linux：

```bash
curl http://127.0.0.1:8850/api/ping
```

应返回类似：

```json
{"app":"tonnetz-lite","ok":true}
```

### 5.2 检查页面

打开页面后应看到 Tonnetz 网格、右侧“当前选择 / 五度圈 / 调性 / 输入与检索”和底部“和弦进行”。

浏览器开发者工具的 Console 与 Network 面板中不应出现 404。点击一个三角形应能听到声音，右侧出现和弦名称与分析。

## 6. 更新

1. 先运行 `stop.cmd`（Windows）或按 `Ctrl+C` 停止服务。
2. 备份你修改过的文件。
3. 用新版本覆盖 `index.html`、`assets/`、脚本与文档。
4. 重新启动，并在浏览器中按 `Ctrl+F5` 清除旧缓存。

`assets/js` 使用 ES Module 缓存策略由服务器控制；随附的两个服务器默认不为 HTML/JS/CSS 使用长期缓存（图片可能有短缓存），一般不需要手动清缓存。

---

## 7. 卸载

1. Windows 双击 `stop.cmd`；macOS / Linux 在终端按 `Ctrl+C`。
2. 删除整个 `Tonnetz-Lite` 文件夹。
3. 如创建过快捷方式，删除桌面上的 `Tonnetz Lite.lnk`。
4. 如需清除浏览器本地状态：开发者工具 → Application → Local Storage，删除 `tonnetz-lite:circleMode`。

项目不写注册表、不装服务、不在系统目录留下文件。

## 8. 故障排查

| 问题 | 可能原因 | 解决 |
|---|---|---|
| `Failed to load module script` | 用 `file://` 直接打开 | 通过本地 HTTP 服务访问 |
| `ERR_CONNECTION_REFUSED` | 服务器未启动或已停止 | 重新运行 `launch.cmd` / `start.sh`，检查 `.runtime\url.txt` |
| 提示 `HttpListener` 不支持或启动超时 | 系统/安全软件限制了 HTTP.sys | 安装 Python 3 后运行 `python serve.py --port 8850`，或改用 GitHub Pages |
| 端口被占用 | 其他程序或旧实例占用 | 关闭旧实例，或 `python3 serve.py --port 9000` |
| 页面能开但没有声音 | 浏览器自动播放限制 / 静音 | 点击页面一次；检查右上角声音按钮和系统音量 |
| 四部和声显示红色 | 进行在严格 SATB 下无解 | 查看“问题点”和“修改建议”，调整和弦、转位或重复音 |
| 音集没有完整显示 | 四声部无法容纳过多音/自由音集 | 扩展和弦可能省略音；自由音集与 9 音以上通常无法直接严格 SATB |
| MIDI 无法导入 | 播放器/DAW 不支持 SMF format 1 | 使用支持标准 MIDI 文件的 DAW、MuseScore 或 VLC 试听 |
| 文字显示异常 | 系统缺少中文字体 | 安装常见中文字体；界面优先使用 Segoe UI / 微软雅黑 / 苹方 |

仍未解决时，请提交 Issue，并附上：操作系统、浏览器版本、复现步骤、Console 报错截图，以及相关的和弦进行文本。

## 9. 安全与隐私

- 两个随附服务器都只绑定 `127.0.0.1`，不监听局域网。
- 页面没有外部请求，不加载 CDN 字体、统计脚本或第三方 SDK。
- `serve.py` 只提供当前目录的静态文件，不执行上传内容。
- 不要将本项目改造成对公网开放的文件服务器；它只适合本地静态页面。
